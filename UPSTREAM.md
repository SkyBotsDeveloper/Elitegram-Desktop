# Upstream and attribution

Elitegram Desktop is a modified build of [Telegram Desktop](https://github.com/telegramdesktop/tdesktop).

- Verified source base: Telegram Desktop **v7.2.9**
- Verified upstream commit: `fb2e33209517e1a34637d837bfadb3783f2fd59c`
- Elitegram Desktop project release: **v1.0.0** (separate from the upstream application version)

The upstream Git history, copyright headers, [GPLv3-or-later license](LICENSE), and [OpenSSL linking exception](LEGAL) are retained. The original [upstream README](UPSTREAM_README.md) remains available, including its third-party acknowledgements. Git submodules have their own upstream origins and license terms; the two audio-related submodules require Elitegram-specific source revisions for this release.

Elitegram is independent software and is not affiliated with or endorsed by Telegram.
