# Elitegram Desktop v1.0.0

The first public Windows x64 release of Elitegram Desktop, derived from Telegram Desktop v7.2.9.

## Highlights

- Ghost Mode with per-account presence, typing/recording, read, and story-view controls, plus Seen on Reply where applicable.
- Keep Deleted Messages for eligible ordinary private cloud chats, using a separate local, view-only archive.
- Architecture for up to 100 account slots; five accounts were manually exercised, not 100 simultaneous accounts.
- Data-center information in the app.
- Selected Audio, Device Audio, Voice Effects, and No Mic Blink call tools.
- Elitegram Windows branding, an isolated profile, and a native Chats sidebar promo card.

## Important scope

Keep Deleted Messages does not promise retention of protected, view-once, TTL/self-destruct, secret, or every other deleted item. Ghost Mode and No Mic Blink are not anonymity guarantees. Audio/call behavior can depend on Telegram call state, Windows audio devices, and routing. Open source does not mean bug-free or vulnerability-free.

## Download and verification

Download `Elitegram-Desktop-v1.0.0-Windows-x64.zip` and `SHA256SUMS.txt` from the [GitHub Release](https://github.com/SkyBotsDeveloper/Elitegram-Desktop/releases/latest). Compare the ZIP's SHA-256 against the checksum file before extracting it. Keep the extracted files together and run `Elitegram.exe`.
