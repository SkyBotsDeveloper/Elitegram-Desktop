# Reporting security issues

Please report suspected Elitegram Desktop vulnerabilities privately through the repository's [GitHub security advisory reporting](https://github.com/SkyBotsDeveloper/Elitegram-Desktop/security/advisories/new), if available. If that route is unavailable, contact the maintainer through [@iflexsid on Telegram](https://t.me/iflexsid) to arrange a private report.

Do not post authentication keys, session files, private Telegram data, or exploit details in public issues or chats. Include a concise reproduction, affected release, and impact, with sensitive material removed. Please allow time for triage before public disclosure.

For vulnerabilities in upstream Telegram Desktop or Telegram infrastructure rather than Elitegram modifications, use the appropriate upstream reporting route.
